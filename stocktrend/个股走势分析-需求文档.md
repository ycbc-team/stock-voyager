## 3. 数据源与职责划分（核心）

数据获取采用**三个已连接 MCP 连接器**，各司其职：

| 字段组 | 数据源 | 调用工具 | 口径 |
|---|---|---|---|
| 行情/估值（close/prev_close/open/change/chg_pct/amount/turnover/pb/mcap/pe/div） | 腾讯自选股 | `data_quote(codes=..., date=D)` | **收盘**（带日期参数） |

## 4. 主要口径规则（红线与兜底）

### 4.1 收盘口径红线（最高优先级）
- 所有行情、资金字段**必须带日期参数取收盘值**，**绝不取盘中实时价、绝不编造**。
- 数据日期锚定 `D` = 当日交易日（如 2026-08-24），报告所有数据点对应 D 收盘。

### 4.2 非交易日兜底校验
- 定时任务只排除周末，法定节假日仍可能触发。
- 以「拉数据兜底」判断：并行拉取三源 D 当日数据，若**任意核心源**（westock 行情 / 妙想主力净流入）对 D 返回空或异常 → 判定非交易日，**直接结束、跳过更新，不改写任何文件**。
- 三源均取到数据 → 交易日，继续。

### 4.3 两融（margin）T-1 机制
- 交易所当日两融数据一般**盘后晚间**才发布，D 当天拉取常为空。
- 处理顺序：
  1. 源 B 主查询若已带出两融 → 直接用；
  2. 否则**单独补查最近交易日 D-1 的真实融资余额/买入额**；
  3. 将 D-1 真实值写入 `margin_balance` / `margin_buy`，并在 `real_quotes.py` docstring **如实标注「两融为 T-1（D-1 真实值）」**；
  4. 实在补不到 → 标注缺失，**不虚构**。

### 4.4 10Y 国债收益率取值规则
- Wind EDB 官方代码 `S0059749`（中债 10Y）**无权限（受限指标）**，禁用。
- 改用东方财富宏观 `mx_macro_data`（query="中国10年期国债收益率 中债 最新值"），取「中债国债到期收益率:10年(%)」。
- D 当日未发布（返回 "-"）→ **沿用上一交易日真实值**，并在 docstring 标注。
- **多源互证**：中债估值中心 / 中国外汇交易中心（CFETS）/ 中证指数公司三口径交叉验证（如 2026-08 区间 1.679~1.692%）。

### 4.5 北向持股 T-1 属正常
- Wind 北向（陆股通）为最新 **T-1** 口径（等同上一交易日），属正常，**不当缺失处理**。

### 4.6 缺失数据处理原则
- 某源缺失时尽量用其他源补全；
- 确实补全不了 → 如实标注（`—` 或 docstring 注明口径），**严禁虚构数字**。

### 4.7 单位口径（写入 real_quotes.py 的字段单位）
| 字段 | 单位 |
|---|---|
| `amount` / `mcap` | 元 |
| `north_shares` | 股 |
| `main_inflow` | 亿元（含正负号） |
| `margin_balance` / `margin_buy` | 亿元 |
| `turnover` / `chg_pct` / `div` / `pe` / `pb` | 百分数或倍数（按源返回） |

### 4.8 涨跌配色惯例
- A 股惯例：**涨红跌绿**（与中国大陆市场一致，与美国市场相反）。

## 6. 详情页（点击个股后的弹窗）数据与口径

点击首页任一个股卡片即打开该股弹窗详情页（纯 CSS checkbox 方案，免 JS，手机端可用）。页面顶部固定一条 **数据口径声明（databadge）**：本页为 `D` 收盘**静态快照**，行情为**收盘口径（非盘中实时）**。

### 6.1 数据口径三级分层（先分清数据从哪来、多久更新）

| 层级 | 数据 | 来源 | 更新频率 |
|---|---|---|---|
| ① 实时行情/资金面 | 收盘价/涨跌幅/成交额/换手率/PB/总市值/PE(TTM)/股息率、主力净流入、融资余额/买入、北向持股 | 腾讯自选股 + 东方财富妙想 + Wind（每日三源拉取） | 每日覆盖 |
| ② 财务历史 | 近5年分红（2021-2025：dps/eps/payout）、近3年质量（2023-2025：debt/roe/ocf_ps/gross） | Wind 年报口径 | 年度更新（静态，随生成器维护） |
| ③ 模型估算/人工维护 | 巴菲特评分、合理PE中枢、目标价、安全边际、风险/总结/重大事件/优化提示 | 生成器模型 + 人工静态标注 | 随配置维护（非实时） |

### 6.2 八大模块明细（数据 → 口径）

**模块1 · 行情快照（D 收盘后）**
- 数据：A1 顶部 4 张指标卡（收盘价/涨跌幅/总市值/股息率）+ 今开/昨收、成交额、换手率、PB
- 口径：腾讯自选股 `data_quote(date=D)` **收盘口径**，非盘中实时

**模块2 · 买卖决策与建仓**
- 数据：是否推荐入手结论条（✅推荐/🟡小仓/⏳观望）、是否处于低点（估值视角）、当前PE、合理PE中枢（fair_pe）、建议买入PE（= fair_pe × 0.85，安全边际85%）、距击球区、估值目标价、三档建仓价位
- 口径：PE中枢/目标价/安全边际为**模型估算**（基于公开财报）；三档建仓价位按**目标股息率反推**（仅含 FINANCIALS 的个股有真实值，否则占位提示）；EPS ≈ D 收盘价 ÷ PE(TTM)

**模块3 · 资金面动态**
- 数据：北向持股比例+数量、主力净流入(D)、融资余额、融资买入(D)
- 口径：北向 = Wind **T-1**；主力净流入 = 妙想**当日**；融资余额/买入 = **最近可得交易日真实值（T-1）**——模块底部 note 明确标注三项口径

**模块4 · 盈利质量与排雷**（仅含 FINANCIALS 的个股，现 32 只全量）
- 数据：近3年表（资产负债率/ROE加权/每股经营现金流/销售毛利率）+ 排雷结论（通过/关注/不通过）
- 口径：**Wind 年报口径（2023-2025）**；银行/保险无毛利率 → 显示"—"、排雷跳过毛利率维度（健壮性处理）；经营现金流覆盖分红 = 最近一年 ocf_ps ÷ dps

**模块5 · 分红回报全景**（仅含 FINANCIALS）
- 数据：近5年分红表（每股分红/每股收益/分红率，2021-2025）+ 分红可持续性评分（0-100 + 星级）+ 10万元分红收益测算 + 股息率 vs 无风险利率（利差）
- 口径：分红表 = Wind 年报口径（分红率 = 每股分红 ÷ 每股收益；2025 含中期分红以公告合计为准）；10万测算 = 10万 ÷ 现价 × TTM每股分红（= 现价 × 股息率%）；无风险利率 = 中债10Y（`TREASURY_10Y`，东方财富宏观口径，D 未发布沿用上一交易日）

**模块6 · 巴菲特模型评分**
- 数据：综合评分 0-100 + 仪表盘 + 5 因子条（每因子 得分/满分/明细）
- 口径：**模型估算**。因子权重：ROE盈利能力 30 + 估值合理性PE 25 + 分红回报 15 + 财务稳健/资产质量 15 + 护城河/现金流 15；**金融股按资产质量单独评估**（debt_override）；≥78 优秀 / ≥65 良好 / <65 一般

**模块7 · 风险提示（重点3条）**
- 数据：固定 3 条风险
- 口径：个股风险配置（静态）+ 差异化补充规则（如恒瑞/沈飞零分红无托底、破净周期股须设止损等，人工维护），非实时舆情

**模块8 · 进一步分析 · 一句话总结**
- 数据：一句话总结、护城河、行业趋势、操作思路、仓位约束、优化提示
- 口径：护城河/趋势/优化提示为人工维护静态文本；操作思路按「是否推荐入手」结论动态生成；仓位约束固定为**单只 ≤ 组合 15%-20%**

**可选模块 · 重大事件/催化剂**（仅配置了 `events` 的个股显示，如分众传媒）
- 数据：事件列表（日期 + 内容）
- 口径：**人工维护的静态标注**（非实时新闻流），以公司公告为准；插入模块1后，全部模块编号自动重排（不影响未配置个股）

### 6.3 详情页声明文字（databadge 原文口径）
- 收盘价/涨跌幅/成交额/换手率/PB/总市值/PE(TTM)/股息率 → **腾讯自选股**
- 主力净流入/融资余额/融资买入 → **东方财富妙想**
- 北向(陆股通)持股 → **Wind**
- ROE/毛利率/负债率/合理PE中枢 → **基于公开财报的模型估算**（仅用于巴菲特评分与估值判断）
- 近5年分红/近3年财务质量 → **Wind 年报口径**

## 8. 非功能要求

1. **移动端兼容**：单文件 HTML、无外部依赖、免 JS 弹窗，手机端（mobile Safari/内置浏览器不执行 JS）可完整浏览。
2. **响应式**：media query 置于 CSS 拼接最后（`INDEX_CSS + DETAIL_CSS + MEDIA_CSS`），避免被覆盖导致手机端列数错误；指标卡数字 `white-space:nowrap` 防换行。
3. **历史可回看**：每日归档互不覆盖，累积保留。
4. **数据可信**：全部字段锚定 D 收盘或标注 T-1/沿用口径，绝无虚构。
